# 🔮 Astrology Website

## 📌 Overview

This project is an Astrology Website built using **HTML, CSS, and JavaScript** with a clean and effective user interface. The website takes user input and provides personalized insights based on astrology.

## 🚀 Features

* Collects user details such as:

  * First Name
  * Surname
  * Date of Birth (Day, Month, Year)
* Determines the user's **Zodiac Sign**
* Provides insights about:

  * Personality traits
  * Future predictions
  * Possible life challenges
* Displays a **motivational quote** based on the analysis
* Clean and user-friendly UI

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript

## 🎯 Purpose

The purpose of this project is to practice front-end development skills while building an interactive and engaging web application.

## 📷 UI Highlights

* Simple and clean design
* Easy user input flow
* Responsive layout

## 📌 How It Works

1. User enters their personal details.
2. The application processes the input.
3. It calculates the zodiac sign.
4. Based on the result, it shows:

   * Personality description
   * Future insights
   * Motivational quote

This project helped in strengthening JavaScript concepts and building real-world interactive applications.
